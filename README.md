# Retail Sales & Profit Analysis Dashboard

## 📊 Project Overview
This project analyzes retail sales and profitability using PostgreSQL and Power BI. The analysis includes sales trends, customer insights, profit analysis, KPI reporting, and AI-assisted SQL optimization.

---

## 🛠 Tools Used
- PostgreSQL
- SQL
- Power BI
- AI-assisted SQL validation

---

## 📈 Business Questions Solved
- Which category generated highest sales?
- Which region achieved highest profit?
- Which products caused losses?
- Who are the top customers?
- What are the monthly sales trends?

---

## 🧠 SQL Skills Used
- Aggregations
- GROUP BY
- CASE statements
- CTEs
- Window Functions
- KPI Queries
- Query Optimization

---

## 🔍 Key Insights
- Technology generated highest sales.
- West region achieved highest profit.
- Tables sub-category caused largest losses.

---

## 📊 Dashboard Features
- KPI Cards
- Monthly Sales Trend
- Profit Analysis
- Customer Analysis
- Regional Performance Map
